# دراسة قرار الاستحواذ على أرض سكنية في الرياض

دراسة قرار استثماري تقارن بين فرصتي استحواذ على أراضٍ سكنية في الرياض، مبنية بالطريقة التي يقيّم بها فريق الأبحاث والاستثمار في شركة تطوير عقاري.

## سؤال القرار

أي الفرصتين نستحوذ عليها، إن كانت أي منهما تستحق، وبأي حد أقصى للعرض لكل منهما، وبأي منتج ومزيج وحدات ومراحل، بحيث يتجاوز معدل العائد الداخلي للمشروع العتبة المستهدفة في السيناريو الأساسي، ويبقى فوق الحد الأدنى في السيناريو الهبوطي؟

## الفرصتان

| | العارض | الخالدية |
|---|---|---|
| السوق | شمال الرياض | وسط الرياض |
| المساحة | 10,034.81 م² | 18,591.75 م² |
| سعر الطلب | 6,500 ريال/م² | 2,700 ريال/م² |
| الإجمالي | 65,226,265 ريال | 50,197,725 ريال |

## خيارات القرار

1. الاستحواذ على العارض فقط
2. الاستحواذ على الخالدية فقط
3. الاستحواذ على الاثنتين على مراحل
4. التفاوض على إحداهما بحد أقصى للعرض
5. رفض الاثنتين

## المنهجية

القدرة الشرائية ← فجوة العرض والطلب ← التسعير التحوطي ← مزيج الوحدات (البرمجة الخطية) ← الجدوى المالية (التدفقات النقدية المخصومة) ← السيناريوهات والحساسية ← القرار
